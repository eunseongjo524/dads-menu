Dad's Menu QR prototype

Open index.html in a browser to preview the menu.
The page is already arranged in the same order as the printed menu:
Main: 9 items, then Salad: Grilled Baby Napa Cabbage Salad.

Languages: Korean / English / Japanese / Chinese.

For a real QR code used by customers, upload this folder to a static web host
such as GitHub Pages and make a QR code pointing to the resulting URL.
